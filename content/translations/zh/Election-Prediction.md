# 项目概览

<img src="{{ site.url }}{{ site.baseurl }}/images/election/trump1.png" alt="选举预测项目概览">

本项目通过处理和分析人口普查及 Twitter 数据，尝试预测特朗普能否赢得 2020 年美国总统选举。项目有以下三个值得关注的方面：

1. 机器学习所用数据集较为全面。对每一个国会选区，数据涵盖就业情况，包括失业率、劳动力、农业从业情况等，以及种族构成、教育和医疗保障水平，如医保覆盖率。我们还加入宏观经济变量，如基尼系数，以及投票率、此前得票等选举相关变量。我们认为，已经纳入了大多数会影响选举结果的变量；多种模型和严格验证也增强了结果的可信度。

2. 我们还使用 Twitter 数据和文本挖掘，分析人们对不同候选人的感受，以及候选人在 Twitter 上的受欢迎程度，以补充分析。毕竟，候选人的个人特征也会显著影响选举结果。

3. 除了预测 2020 年总统选举，项目还产生了一些有意思的附带结果。例如，机器学习的特征重要性揭示了哪些因素对总统选举影响最大；我们还分析了民主党中最有竞争力的候选人。这两项结果都可能有助于竞选规划。此外，还通过各候选人推文的词云，分析他们最关心的问题。下图展示特征重要性。

# 第一部分：通过机器学习预测总统选举结果

## 数据来源

我们通过 API 和网页抓取，从美国人口普查局和美国社区调查取得数据。数据集包含 435 个国会选区在 2012、2016 和 2018 三个年份的数据。如前所述，合并后的数据集涵盖就业、种族构成及选举相关变量等重要方面。我们还取得 2012 和 2016 年总统选举结果，作为后续分析中的因变量。

## 数据抓取与收集

我们使用 Census API，从[美国人口普查数据接口](https://api.census.gov/data)收集国会选区数据。不同年份、不同变量需要对应的代码，例如，2009 年各选区人口的代码是“B01003_001E”。此外，需要将字典转换为 pandas DataFrame。除了人口和种族等人口特征，也纳入医疗、经济、教育等因素。由于变量代码可能随年份变化，我们为不同年份编写了不同函数，例如 get_data_2009 和 get_data_2011。州级属性也采用类似方法。

## 数据预处理与可视化

取得人口普查数据、投票率和[此前选举结果数据](https://www.dailykos.com/stories/2012/11/19/1163009/-Daily-Kos-Elections-presidential-results-by-congressional-district-for-the-2012-2008-elections)后，需要将它们合并，为每一年建立汇总 DataFrame。我们以各国会选区的唯一键“CD-ID”执行 merge。

选区选举结果原本以民主党和共和党的得票比例记录。但按照“赢家通吃”规则，计算州级最终获胜者时，需要汇总一个州内各选区的实际票数，因此另外创建列来保存各选区的票数。同时，编写“who_win”函数记录各州获胜者；同一个州的所有选区会得到相同结果。结果保存在“df_year_result”中，再通过 groupby 汇总，即可计算不同选举年份的票数与美国最终当选总统，如下图所示。特别地，由于 2010 年人口普查，[2012 年结果需要进行一些调整](https://en.wikipedia.org/wiki/2012_United_States_presidential_election)。

## 特征工程与建模

用于建模的数据中，2012 年有 423 行，2016 年有 435 行，2018 年有 435 行；2018 年只有自变量，因为需要预测其因变量。方法上，我们同等处理 2012 和 2016 年数据，即使对应的是同一个国会选区，也将其视为不同选区。在这里，我们假设选举结果完全由最近的过去和当前状况决定。比较不同模型后选出最优者。此后的主要工作是验证交叉验证误差能否有效代表预测误差，以及分析模型的用途和误差可能存在的位置。

首先建立初始基准模型。将 2012 和 2016 年数据合并，确保列一致；删除部分州相关列，使用各州经纬度，将这个唯一的分类变量转换为数值。随后，对数据集进行标准化，使均值为 0、方差为 1。最后，拟合多个模型，包括支持向量回归、梯度提升树、XGBoost 和 Lasso／Ridge 回归，并通过交叉验证调整超参数。使用的算法见下图。

<img src="{{ site.url }}{{ site.baseurl }}/images/election/trump2.png" alt="建模算法比较">

Lasso 回归的基准结果最有希望：结果表明，对于 90% 的国会选区，模型平均能够可靠判断两党之间大于 6% 的差距，因此可以覆盖大多数州。不过，在这个问题中，交叉验证误差是否能够有效代表测试误差仍需检验。我们先用同样方法预测 2016 年选民构成，检查交叉验证的误差衡量方式是否有效。得到的错误率约为 8.9%，总体较为一致。由于数据点数量只有一半，误差略高也符合预期。

通过预测差值的正负，可以确定每个选区的获胜党派。模型在验证集中有 93% 的选区预测符号正确，也就是选区获胜党派预测正确。可视化显示，剩余预测错误的 7%，与原始数值的差距在 10%—15% 以内。

对 Lasso 回归而言，我们发现：基于过去样本得到的交叉验证误差，可以较好地代表使用过去数据训练模型、再预测未来各选区投票结果时的测试误差。进一步分析时，可以按系数绝对值排序，识别数据集整体最重要的特征。为了在更细层面理解特征，还可以使用 GitHub 上的 SHAP 库，对每个选区的特征重要性排序。

我们也可以汇总某一州的所有选区，识别州级重要特征。这有助于理解一个州为何会在下一次选举中转而支持另一个党派。图 7 和图 8 以加利福尼亚州 2016 和 2020 年为例。现在，可以用模型预测 2020 年各选区两党得票比例之差。

<img src="{{ site.url }}{{ site.baseurl }}/images/election/trump8.png" alt="州与选区层面的特征解释">

**最终，我们预测特朗普将赢得 2020 年总统选举。**

# 第二部分：预测验证——Twitter 文本挖掘

前面的建模有一个关键假设：人口特征和生活水平指标对个人政治观点起决定性作用，因此可以用它们预测个人将投给哪个党派。但这是否完全符合事实？更准确地说，是否对所有人都成立？可能并非如此，因为候选人的个人特征也会明显影响政治偏好。因此，项目第二部分对候选人开展文本挖掘。

## 数据来源

共和党方面，我们选择时任总统唐纳德·特朗普；民主党方面，选择当时最受欢迎的七位候选人，见图 9。

通过 Twitter API 获取两部分数据：各候选人本人发布的推文，每人 3000 条，受 Twitter API 数量上限限制；近期提及各候选人的推文，也各取 3000 条。我们还发现一个有意思的情况：对特朗普而言，3000 条的上限只能回溯到 2019 年 5 月，意味着他平均每天发 20 条推文。

<img src="{{ site.url }}{{ site.baseurl }}/images/election/trump9.png" alt="参与文本分析的候选人">

## 情绪分析

为了解选民对不同候选人的态度，我们对提及各候选人的推文进行了 VADER 情绪分析。在 8 类情绪和 2 类情感中，选择正面、负面、信任和愤怒四项。图 10 显示，特朗普当时面临支持度问题：负面和愤怒得分相对较高，正面和信任得分较低。

结果也揭示了特朗普最大的竞争对手，即伯尼·桑德斯和科里·布克，两人都受到 Twitter 用户的广泛喜爱。

<img src="{{ site.url }}{{ site.baseurl }}/images/election/trump10.png" alt="候选人情绪分析比较">

## 受关注程度比较

除了人们对候选人的总体感受，我们也关心候选人的受关注程度。毕竟，在这个时代，人们是否关注某位候选人，也可能改变竞争局面。获得最多关注的人，也最有潜力赢得选票。因此，我们检查了推文的平均点赞数与平均转发数。

图 11 和图 12 显示，特朗普在 Twitter 上最受关注：他的平均点赞数和转发数均为最大竞争对手伯尼·桑德斯的两倍。

## 各候选人的词云

我们还为各候选人的推文制作词云，分析其主要话题。可以看到，弹劾和民主党是特朗普频繁提及的话题；他似乎很喜欢提及竞争对手，大概不是为了称赞他们。此外，多数候选人经常在推文中提及自己的政治主张，结果见图 13。例如，柯尔丝滕·吉利布兰德经常提到女性，可以推断她很关注女性权利。

<img src="{{ site.url }}{{ site.baseurl }}/images/election/trump13.png" alt="各候选人推文词云">

综合人口特征、经济指标、投票率、此前得票比例等信息，我们预测特朗普会赢得 2020 年总统选举。文本挖掘结果显示，虽然人们对特朗普的总体态度并不十分正面，但按 Twitter 数据衡量，他仍是最受关注的候选人，因而有较大潜力获得公众关注与选票。这进一步验证了模型的预测结果。祝贺特朗普先生！
