本站由Annan Chen维护。访问统计用于了解文章阅读、项目入口使用和页面在不同设备上的表现。点击“允许统计”并同意境外处理后才开始记录，拒绝不影响浏览。你可以随时从页脚的“统计设置”撤回同意。

## 记录内容

| 内容 | 保存方式 |
| --- | --- |
| 页面与操作 | 页面路径、页面语言、来源域名、时间、项目或链接点击、阅读进度 |
| 回访与会话 | 随机访客ID、会话ID、是否回访 |
| 网络 | 脱敏IP网段（IPv4 /24、IPv6 /48）、国家或地区、省或州、运营商及ASN（托管平台提供时） |
| 访问环境 | 设备、浏览器及系统类别、浏览器语言、时区、按100像素取整的窗口与屏幕尺寸 |
| 同意记录 | 本说明版本、同意时间、境外处理选择 |

原始IP只在请求处理中用于生成脱敏网段，不写入应用数据库。网络字段缺失时留空；VPN、共享网络和托管转发可能影响判断。本站不使用这些信息匹配真实身份。

统计不保存姓名、邮箱、完整浏览器标识、精确定位、网址查询参数或表单内容，也不读取其他网站的Cookie或使用设备指纹。

## 保存与删除

本站使用第一方本地存储保存同意选择和随机统计标识，没有另设统计Cookie。同意选择和访客ID90天后到期，会话在30分钟无活动后结束。不同设备、隐私窗口和清理浏览器数据会影响访客数。应用中的详细事件最多保留90天，每日清理过期记录。

在“统计设置”点击“撤回同意并删除记录”，会停止记录、清除本浏览器的统计标识，并请求删除与此标识关联的服务器记录。网络中断时会保留一项待删除请求，下次访问自动重试。已经清除的浏览器标识无法用来定位旧记录，旧记录仍按90天上限到期删除。

统计后台和CSV导出仅站点所有者可查看。本站尊重浏览器的“禁止跟踪”和Global Privacy Control设置。其他数据查询或权利请求可通过[站点所有者的LinkedIn](https://www.linkedin.com/in/annan-chen-1227b5138/)联系。

## 服务与境外处理

统计请求发送至[本站独立统计服务](https://annan-site-analytics.regalpig32.chatgpt.site/)，由OpenAI Sites及Cloudflare基础设施处理，可能在中国大陆以外处理和存储。该用途需要你单独勾选同意，拒绝后不会发送统计事件。服务商的基础设施政策见[OpenAI隐私政策](https://openai.com/policies/privacy-policy/)和[Cloudflare隐私政策](https://www.cloudflare.com/privacypolicy/)。

GitHub Pages和统计服务的托管平台会按各自规则处理网络请求日志。本页说明的是本站应用保存的统计记录。
