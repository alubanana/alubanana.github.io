Annan Chen maintains this website. Optional analytics help understand article readership, project entry points and how pages work on different devices. Recording starts after you select “Allow analytics” and agree to overseas processing. Declining does not affect browsing. You can withdraw through “Analytics settings” in the footer.

## What is recorded

| Category | Stored information |
| --- | --- |
| Pages and actions | Page path, page language, referring domain, time, project or link clicks and reading progress |
| Visits and sessions | Random visitor and session identifiers, returning status |
| Network | Masked IP prefix (IPv4 /24 or IPv6 /48), country, region or state, network operator and ASN where the host provides them |
| Environment | Device, browser and operating system categories, browser language, timezone, viewport and screen sizes rounded to 100 pixels |
| Consent | Notice version, time of consent and overseas processing choice |

Raw IP addresses are used during the request to generate a masked prefix and are not written to the application database. Missing network fields remain blank. VPNs, shared networks and hosting proxies can affect these values. This website does not match these records to real identities.

Analytics do not store names, email addresses, full browser identifiers, precise location, URL query parameters or form contents. They do not read other websites’ cookies or use device fingerprinting.

## Retention and deletion

First-party local storage keeps your choice and random analytics identifiers; no additional analytics cookie is set. Consent and visitor IDs expire after 90 days. A session ends after 30 minutes of inactivity. Separate devices, private windows and cleared browser data affect visitor counts. Detailed application records are retained for at most 90 days, with daily expiry cleanup.

Select “Withdraw and delete records” in “Analytics settings” to stop recording, clear this browser’s analytics identifiers and request deletion of server records associated with the identifier. If the request fails, a pending deletion request is kept and retried on a later visit. An identifier already removed from your browser cannot locate older records; these still expire within 90 days.

Only the site owner can view the dashboard or export CSV. The tracker respects Do Not Track and Global Privacy Control. For other data or rights requests, contact the [site owner on LinkedIn](https://www.linkedin.com/in/annan-chen-1227b5138/).

## Service and overseas processing

Events are sent to this website’s [separate analytics service](https://annan-site-analytics.regalpig32.chatgpt.site/), hosted using OpenAI Sites and Cloudflare infrastructure. Processing and storage may take place outside mainland China. You must separately agree to this processing; declining prevents analytics events from being sent. See [OpenAI’s privacy policy](https://openai.com/policies/privacy-policy/) and [Cloudflare’s privacy policy](https://www.cloudflare.com/privacypolicy/) for their infrastructure policies.

GitHub Pages and the analytics hosting platform process network request logs under their own policies. This page describes the records saved by this website's analytics application.
