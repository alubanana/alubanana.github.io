---
title: Site analytics
description: What this website measures and how to control it.
---

This website uses a separate analytics service to record page views, note reading progress, and clicks on projects or external links. Records include the page path, language, referring website, device category, browser category, country or region, and time.

The analytics application does not store raw IP addresses, names, email addresses, full browser identifiers, precise location, URL query parameters or form contents. Region information comes from the network request and may be affected by VPNs or network gateways.

An anonymous identifier is stored in this browser and renewed after 90 days to estimate returning visits. A session ends after 30 minutes of inactivity. Different devices, private windows, cleared browser data and tracking blockers affect visitor counts. Detailed events are retained for 90 days.

Only the site owner can view the analytics dashboard. The tracker respects Do Not Track and Global Privacy Control. The footer control also lets you turn analytics off and remove the site's anonymous analytics identifiers.

GitHub Pages and the analytics hosting platform process network request logs under their own policies. This page describes the records saved by this website's analytics application.
